# iPhone Duo Design

Agent skill: design SwiftUI iOS apps for the foldable iPhone Duo, with the mistakes to avoid

## Included skills

- `iphone-duo-design`

## Installation

```bash
npx github:AustineA/iphone-duo-design
```

This installs the skills separately at:

```text
~/.agents/skills/iphone-duo-design/
```

It then symlinks them into detected Claude Code, Codex, Cursor, Windsurf, Antigravity, Trae, and Amp installations.

Other commands:

```bash
npx github:AustineA/iphone-duo-design status
npx github:AustineA/iphone-duo-design uninstall
```

## Usage

After installation, Optimise this app for iPhone Duo.

## Package structure

```text
bin/
  install.mjs
skill/
  iphone-duo-design/
    SKILL.md

```
